Getting your schedule in

Export from MS Project with File › Save As › Excel Workbook (or your existing export map). Any of these column names are recognised automatically:

  • Required: Name, Start, Finish
  • Hierarchy: Outline Level and/or WBS (either works; both is best)
  • Recommended: ID, Duration, % Complete, Summary, Milestone, Critical, Predecessors, Resource Names, Baseline Start, Baseline Finish, Notes
  • Anything else (Work Order, Operation, Work Centre, FLOC, Text fields…) is shown on the job card and is searchable.

Dates can be Excel dates or text like Mon 16/11/26 7:00 AM. Rows must stay in Project's order (top to bottom), which is how Project exports them.

Hosting: put this page and your export named schedule.xlsx in the same folder (e.g. GitHub Pages) and it loads automatically. ?file=other.xlsx picks a different file.

Load from a Google Sheet

Paste the sheet's link. It must be shared as Anyone with the link – Viewer. The first tab is used unless the link includes #gid=… for another tab.

Auto-refresh:

The link is remembered in this browser only. To set it for everyone, edit CONFIG.SHEET at the top of the page's code.
